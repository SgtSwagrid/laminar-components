object Css

Stylesheets written in Scala, with Laminar's own typed style props: rules for selectors, holding what an element's inline styles cannot, its states (:hover), its parts (::after), and styles for some media alone (@media), with keyframes and font faces besides.

Stylesheets written in Scala, with Laminar's own typed style props: rules for selectors, holding what an element's inline styles cannot, its states (:hover), its parts (::after), and styles for some media alone (@media), with keyframes and font faces besides.

A rule nested in another applies within it, its & standing for the outer rule's selector (else a descendant of it), as in CSS nesting, but each is written out whole, for any browser:

import com.raquo.laminar.api.L.*
import com.alecdorrington.laminarcomponents.Css.{media, rule}

val styles = Stylesheet(
 rule(".card")(
   padding.px(12),
   borderRadius.px(8),
   rule("&:hover")(backgroundColor := "#eef"),
   rule(".card-title")(fontWeight.bold),
   media("(max-width: 600px)")(padding.px(8)),
 ),
)

Import the builders by name, as Laminar has a media of its own.

object Glide

Slides the elements a change moves from where they were drawn into their new places, rather than letting them jump there: where each stood is read before the change and again once it is laid out, and each that moved is drawn from where it stood and slid home. A block slides by transform; an inline element, which takes none, by its offsets, so it must be position: relative. Nothing slides for a reader who would rather nothing moved of itself.

final class Writes

The writes this client makes to one part of the server's state, kept so that a read of that part never undoes an edit made here:

The writes this client makes to one part of the server's state, kept so that a read of that part never undoes an edit made here:

  • A read is used only if no write began while it was on its way, nor was on its way when it began. Otherwise it is read again once the writes are done (settled).
  • A value read replaces the one on screen only where that is what the server was last known to hold; otherwise it is an edit not yet sent.

Values are recorded against the thing they belong to, usually the Var holding them, compared by identity.

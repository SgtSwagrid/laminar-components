TextCaret

com.alecdorrington.laminarcomponents.TextCaret
See theTextCaret companion object
class TextCaret(aside: String)

Offsets in the text of an element, read from points on the screen and from the page's selection, and where a caret at one stands: what a field drawn over rendered text, or a highlighter, needs to know where the reader is. The text of elements matching aside, such as notes drawn between the words, is no part of the element's own, so it is skipped, a point within it counting as where it stands.

Value parameters

aside

The selector of the elements whose text is skipped.

def spot(root: Element, text: String, offset: Int): Option[Spot]

Finds where a caret at an offset of an element's text stands: before the character there, else after the one before it, so that a caret at a wrap stands at the start of the next line, as a field's does. A line break is drawn at the end of its line, so a caret after the last one stands a line below it.

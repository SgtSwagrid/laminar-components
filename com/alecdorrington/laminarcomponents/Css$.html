Css

com.alecdorrington.laminarcomponents.Css
object Css

Stylesheets written in Scala, with Laminar's own typed style props: rules for selectors, holding what an element's inline styles cannot, its states (:hover), its parts (::after), and styles for some media alone (@media), with keyframes and font faces besides.

A rule nested in another applies within it, its & standing for the outer rule's selector (else a descendant of it), as in CSS nesting, but each is written out whole, for any browser:

import com.raquo.laminar.api.L.*
import com.alecdorrington.laminarcomponents.Css.{media, rule}

val styles = Stylesheet(
 rule(".card")(
   padding.px(12),
   borderRadius.px(8),
   rule("&:hover")(backgroundColor := "#eef"),
   rule(".card-title")(fontWeight.bold),
   media("(max-width: 600px)")(padding.px(8)),
 ),
)

Import the builders by name, as Laminar has a media of its own.

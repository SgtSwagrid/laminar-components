CssProps

com.alecdorrington.laminarcomponents.CssProps
object CssProps

The style props Laminar lacks, among them the logical properties (which follow the text's direction), grid layout, and the font face descriptors (Css.fontFace), each set as Laminar's own are: insetInlineStart.px(0) will not do, as these take any value, so insetInlineStart := "0".

Import them by name or all at once (CssProps.*): if Laminar gains one, the two clash where it is used, and this one should go. Two are named apart from attributes Laminar has: translation and fontSource.
